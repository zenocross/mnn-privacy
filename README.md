# mnn-privacy

Privacy policy for the Marites News Network (MNN) Facebook Page and its
publishing application, **Media Platform Manager**.

Published via GitHub Pages. The live page serves as both URLs Meta's App
Dashboard asks for:

- **Privacy Policy URL**
- **Data Deletion Instructions URL**

Everything lives in `index.html` — a single static page, no build step, no
scripts, no cookies. Edit it and push; GitHub Pages redeploys in about a
minute.

The contact address appears twice in `index.html`. Change both if you move
to a dedicated alias.
